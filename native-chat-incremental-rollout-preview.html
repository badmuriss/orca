Native chat now; agent-TUI handoff later

This is the split proposal. The existing Native chat setting remains the master switch; a nested setting lets developers explicitly choose the updated structured runtime. The terminal↔agent-TUI handoff is deferred to a separate PR so this release has one clear, testable ownership path.

Approval requested for this visible split:

The nested switch remains off by default and the handoff controls are not shown in this slice.

  1. The existing “Native chat” switch remains the master switch.
  2. A nested “Use updated structured native chat” switch appears only when Native chat is enabled. Off keeps the existing PTY-backed native chat; on enables only proven Codex structured sessions.
  3. Terminal sessions, workspace terminals, and unsupported providers remain available. A native chat can open a separate workspace shell, but it does not switch ownership to an agent TUI in this PR.

What users see after each landing slice

This is the approved landing order for the split; the full branch remains the ad-hoc test vehicle.

Slice A
Ownership and recovery core

No visible change. Existing terminal sessions remain the normal product path.

Slice B
Opted-in native creation

Choosing Codex or Claude creates one structured session and activates its exact chat tab.

Slice C — separate PR
Qualified agent-TUI handoff

A later PR can add “Open in agent terminal” after provider-specific process and resume proof passes. It is not present in the native-chat ad-hoc build.

Slice D
Claude parity and mobile

The same visible rules apply to Claude and supported mobile clients after provider-specific proof passes.

Ordinary users

  • No visible change unless Native chat is already enabled.
  • No removed terminal action.
  • No structured-session refusal in the ordinary terminal path.

Explicitly opted-in users

  • The updated runtime is never enabled without the nested opt-in.
  • No silent fallback after an uncertain prompt delivery.
  • No second writer when process identity cannot be proved.
